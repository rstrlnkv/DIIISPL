# DIIISPL

Менеджер раскладок мониторов для Windows 11: раскладка собирается внутри программы, профиль переключается горячей клавишей, а вместе с ним переключается HDR (и в сборках Dev — вид панели задач).

## Установка

Пакет `.msi` лежит в [выпусках](https://github.com/rstrlnkv/DIIISPL/releases). Ставится как обычная программа: в `C:\Program Files\DIIISPL`, с записью в списке установленных, откуда её и удаляют. Работающую копию установщик закрывает сам. Профили лежат отдельно, в `%AppData%\DIIISPL`, и переустановку с удалением переживают.

Windows покажет издателя неизвестным, а SmartScreen может предупредить: программа подписана самодельным сертификатом, и его корень на вашей машине не установлен. Обновления при этом программа сверяет с отпечатком этого же сертификата и чужой пакет не поставит.

Автозапуск включается в меню значка в трее — «Запускать при входе в Windows».

Установка без вопросов:

```
msiexec /i DIIISPL-<версия>-x64.msi INSTALLFOLDER="D:\Programs\DIIISPL" INSTALLSHORTCUT=0 /qb
```

## Возможности

| Возможность | Что делает |
|---|---|
| Профили раскладок | Хранит в файле профиля, где стоит каждый монитор, его разрешение, частоту, поворот, основной ли он и дублирование |
| Опознание по EDID | Узнаёт монитор по производителю, модели и серийному номеру, так что смена порта HDMI или DP раскладку не теряет |
| Горячая клавиша и значок в трее | Переключает профиль клавишей или из меню значка |
| Следовать за мониторами | Когда меняется набор подключённых экранов, сама применяет подходящий профиль |
| HDR | HDR — часть профиля, выставляется после применения раскладки |
| Вид панели задач (сборки Dev) | Вид панели задач — часть профиля, свой на каждое состояние экрана |
| Командная строка | Применяет, записывает, перечисляет и удаляет профили; показывает, что подключено и как опознано |
| Языки | Английский и русский встроены; другой язык добавляется текстовым файлом, без пересборки |
| Обновления | Смотрит выпуски на GitHub, ставит пакет, подписанный тем же сертификатом |

Как пользоваться каждой возможностью: [MANUAL.ru.md](MANUAL.ru.md).

## Требования

- **Система:** Windows 11, x64. Установщик 64-разрядный и ставит программу в `C:\Program Files\DIIISPL`.
- **Права:** для установки нужны права администратора (пакет ставится для всех пользователей). Сама программа работает от обычного пользователя и прав не просит.
- **Сеть:** только проверка обновлений и только по адресам ниже; больше ничего не отправляется и не принимается. Проверку можно оставить программе (раз в сутки) или запустить со страницы «О программе».
  - `api.github.com`, HTTPS: список выпусков `rstrlnkv/DIIISPL`.
  - Файл установщика выпуска, HTTPS, по ссылке, которую GitHub даёт в выпуске (`github.com`; загрузку GitHub перенаправляет на своё хранилище). Только когда вы нажали кнопку обновления.
  - Ссылки в окне «О программе» (страница проекта, страница выпусков, Telegram автора) открываются в вашем браузере по щелчку; сама программа их не запрашивает.
- **Изменения вне своих папок:**
  - `%AppData%\DIIISPL`: профили, настройки, переводы, журнал ошибок (см. «Файлы» в [MANUAL.ru.md](MANUAL.ru.md#файлы)).
  - `%TEMP%\DIIISPL-update`: скачанный установщик; следующее обновление его удаляет.
  - `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DIIISPL`: автозапуск, только если вы включили его в меню значка; при удалении программы это значение убирается.
  - `HKLM\Software\DIIISPL`: пишет установщик, помнит папку установки и то, выбирали ли ярлык в меню «Пуск». Ярлык в меню «Пуск» установщик тоже создаёт, если не задано `INSTALLSHORTCUT=0`.
  - Конфигурация дисплеев: применение профиля меняет расположение, разрешение, частоту, поворот, основной монитор, дублирование и состояние HDR ваших мониторов (`SetDisplayConfig`).
  - Глобальные горячие клавиши: клавиша каждого профиля регистрируется на всю систему, так что, пока DIIISPL работает, другие программы её не получают.
  - Только канал Dev: `DIIISPL.ExplorerTAP.dll` загружается в `explorer.exe` и оформляет панель задач изнутри. В стабильном канале этой библиотеки нет.

## Сборка из исходников

Программа собирается одной командой `scripts\build.cmd`; нужны компилятор C# из .NET Framework, который есть в Windows 11 по умолчанию, и git с полным клоном репозитория: номер сборки — число коммитов, поэтому `scripts\build.cmd` отказывается собирать вне полного клона (поверхностный клон, нет git, задана `GIT_DIR`). `scripts\build.cmd dev` собирает канал Dev.

Как раскладка применяется на самом деле, почему панель задач приходится оформлять изнутри проводника, чем собираются установщик, значок и выпуск, что проверено автотестом и как устроен репозиторий — в [INTERNALS.md](INTERNALS.md); краткая карта кода — в [ARCHITECTURE.md](ARCHITECTURE.md). О найденных уязвимостях сообщают так, как описано в [SECURITY.md](SECURITY.md).
